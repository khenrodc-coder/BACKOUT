==============================================================================
4th UPDATE  -  interaction architecture + animation transitions
(roadmap: "Input and interaction architecture" and "Animation transitions")
==============================================================================
DONE
 [x] Interactable / InteractionSystem: doors and beds register as interactables; the best one in
     range (distance + priority) shows a contextual prompt "[E] Open door" / "[E] Sleep (night only)"
     and ONE key (E, or the old F) uses it. New object types only implement the interface.
 [x] ActionLock: one timed action at a time. Weapon switch, door use, firing, reloading, throwing,
     medkits and sleeping can no longer overlap or interrupt each other by accident.
 [x] Door interaction: the right arm reaches out, the door moves at the moment of contact, and it
     aborts cleanly ("TOO FAR" / "DOORWAY BLOCKED") if you walk away or something steps in the way.
 [x] Weapon switch: old weapon lowers, model swaps at ~0.19 s, new weapon raises (no more instant pop);
     fire / reload are blocked during the swap.
 [x] Reload animation per weapon: pistol (mag swap + slide rack), rifle (mag out / in / charging
     handle), shotgun (muzzle up, three shells, pump). All curves start and end at the ready pose.
 [x] Hit reaction: torso knock-back, head/torso twist toward the nearest threat, 0.3 s stagger slow-down.
 [x] Settings are versioned: older files with separate door / sleep keys migrate to the new defaults.
 [x] Tests: InteractionSystem, ActionLock, ReloadPoses, settings migration (32 unit tests total)

NOT YET
 [ ] Loot containers, doors that can be locked / barricaded, vehicle doors (just add Interactables)
 [ ] Vault / climb transition polish, stair and ladder animations
 [ ] Next roadmap stage: 2x houses with natural interiors (modular room builder), then city districts


==============================================================================
5th UPDATE  -  larger houses with natural interiors (roadmap: "reusable house modules")
==============================================================================
Measured first: the soldier is 118 units tall (~65 units per metre) but the old houses had 84-unit walls and 52-unit
doors. A literal 2x leaves rooms ~80 units deep, too small for a bed, so houses are sized for believable rooms:
about 4.6-6.8 m wide and 4.8-5.5 m deep, 168-unit ceilings, 64x132 doors (see core/Dims.java).
DONE
 [x] HouseLayout: seeded floor plans (back bedroom + bath/WC, interior partition with doorways, open living/kitchen,
     windows placed away from tall furniture). Furniture is wall-aligned, slightly imperfect (chairs pulled out and
     turned, open drawers, clothes/books/shoes on the floor); ruined houses add stains and knocked-over chairs.
 [x] Path guarantee: furniture is only accepted if the front door still reaches every doorway (flood fill with a
     20-unit walker radius). Spawn and loot points keep 34 / 24 units of clearance from walls and furniture.
 [x] HouseBuilder + HouseProps: walls with real door/window openings, door frame and leaf, window frames/muntins/
     curtains, per-room floors (wood / dark wood / concrete), ceiling lights, ~25 furniture models, collision for all.
 [x] Zombies route through doorways inside a house (Building.route) instead of pressing against partitions.
 [x] Placement: one houseSpotFree() check (footprint vs buildings, outpost fence, river, lake, roads, world edge);
     riverside doors face away from the river; street lights skip door lanes; ruins stay off house footprints.
 [x] Bed prompt and sleeping share one range (BED_RANGE); porch, shutters, boards, chimney scaled to the new houses.
 [x] Tests: 11 layout tests over 300 random houses (sizes, overlaps, clear doors, bed present, spawn/loot reachable,
     walker never crosses a wall, determinism). Headless game runs: every house walkable from outside through the
     door to every spawn point and bed, on 10 world seeds (11-12 houses per world).
NOT YET
 [ ] Outpost buildings still use the old small shell (their flat roofs are climbable and part of the start area).
 [ ] Second floors / stairs, locked or barricaded doors, loot containers (just add Interactables).
 [ ] A visual pass in a real 3D run: furniture facing, colours and lighting were checked as floor plans only.
 [ ] City districts and chunk streaming (next roadmap stage).
