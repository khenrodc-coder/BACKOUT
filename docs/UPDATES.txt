==============================================================================
4th UPDATE  -  interaction architecture + animation transitions
(roadmap: "Input and interaction architecture" and "Animation transitions")
==============================================================================
DONE
 [x] Interactable / InteractionSystem: doors and beds register as interactables; the best one in
     range (distance + priority) shows a contextual prompt "[E] Open door" / "[E] Sleep (night only)"
     and ONE key (E, or the old F) uses it. New object types only implement the interface.
 [x] ActionLock: one timed action at a time. Weapon switch, door use, firing, reloading, throwing,
     medkits and sleeping can no longer overlap or interrupt each other by accident.
 [x] Door interaction: the right arm reaches out, the door moves at the moment of contact, and it
     aborts cleanly ("TOO FAR" / "DOORWAY BLOCKED") if you walk away or something steps in the way.
 [x] Weapon switch: old weapon lowers, model swaps at ~0.19 s, new weapon raises (no more instant pop);
     fire / reload are blocked during the swap.
 [x] Reload animation per weapon: pistol (mag swap + slide rack), rifle (mag out / in / charging
     handle), shotgun (muzzle up, three shells, pump). All curves start and end at the ready pose.
 [x] Hit reaction: torso knock-back, head/torso twist toward the nearest threat, 0.3 s stagger slow-down.
 [x] Settings are versioned: older files with separate door / sleep keys migrate to the new defaults.
 [x] Tests: InteractionSystem, ActionLock, ReloadPoses, settings migration (32 unit tests total)
