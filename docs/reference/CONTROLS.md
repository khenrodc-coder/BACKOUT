# Proposed Keyboard Controls

| Key | Action |
|---|---|
| W / A / S / D | Move |
| Shift | Sprint |
| C | Toggle crouch |
| Space | Jump; double-tap near a valid ledge to climb/vault if implemented |
| E | Interact / open door / loot / use bed |
| M | Toggle world map |
| I | Inventory |
| F | Flashlight |
| Tab | Character status |
| R | Reload |
| 1 / 2 / 3 | Select weapon |
| Mouse movement | Look |
| Left mouse | Fire |
| Right mouse | Aim |
| Esc | Pause / close map or menu |

Controls should be configurable in Settings. Avoid hard-coding key behavior in multiple classes; route input through a central input/action mapping.
