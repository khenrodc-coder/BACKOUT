# BLACKOUT: The Last Outpost — Reference & Feature Pack

This pack organizes the requested BLACKOUT upgrades for the existing JavaFX 3D project.

## Contents
- `Photo_References/REFERENCE_GALLERY.html` — visual gallery that loads actual reference photos from the internet.
- `Photo_References/REFERENCE_SOURCES.md` — source pages, creator/license notes where available, and intended use.
- `FEATURES_ROADMAP.md` — requested features grouped by system and priority.
- `ANIMATION_AND_INTERACTION_SPEC.md` — player animation and interaction requirements.
- `WORLD_AND_CITY_DESIGN.md` — city layout, larger buildings, streaming, and map requirements.
- `GAMEPLAY_SYSTEMS.md` — survival, zombie AI, weather, vehicles, and events.
- `CONTROLS.md` — proposed keyboard mapping.
- `TECHNICAL_IMPLEMENTATION_NOTES.md` — JavaFX-oriented implementation guidance.
- `WEEKLY_DEVELOPMENT_PLAN.md` — staged implementation sequence.

## Important note about the photos
The images in this pack are **real internet reference links**, not AI-generated images. The current file-generation environment could not directly download binary image files from the source websites. Therefore, the HTML gallery loads the source images online when opened with an internet connection. The source page links are included for attribution, license checking, and alternate download access.

Open `Photo_References/REFERENCE_GALLERY.html` in a browser while connected to the internet.

## Project safety
- Treat this pack as a planning/reference document, not a code replacement.
- Preserve existing working BLACKOUT features and files.
- Implement incrementally and test after each system.
- Do not assume every reference image is licensed for redistribution or commercial use. Check each source page before reusing an image in a published game, marketing material, or asset bundle.
